📄 HTML

El lenguaje que organiza la estructura de nuestras páginas ✦

✦ ¿Qué es HTML?

HTML corresponde a las siglas de HyperText Markup Language, que en español significa Lenguaje de Marcado de Hipertexto.

HTML se utiliza para construir y organizar la estructura de una página web mediante diferentes etiquetas. Estas permiten incorporar elementos como encabezados, párrafos, enlaces, imágenes, listas, tablas, formularios y otras partes que componen el contenido de un sitio.

En ReneeWebCrew, HTML constituye la base de todas las páginas desarrolladas. Posteriormente, estas estructuras son complementadas con CSS para definir su apariencia visual y con Bootstrap para facilitar la distribución y adaptación del contenido.

✦ ¿Qué es una etiqueta HTML?

Una etiqueta HTML es un elemento utilizado para identificar y estructurar el contenido de una página.

Muchas etiquetas utilizan una etiqueta de apertura, contenido y una etiqueta de cierre. 

<p>
    Este es un párrafo.
</p>

Sin embargo, existen elementos como <img> o <input> que no necesitan una etiqueta de cierre tradicional.

✦ Etiquetas HTML de uso común

Encabezados: <h1> a <h6>

Las etiquetas <h1> hasta <h6> permiten representar títulos y subtítulos dentro de una página.

La etiqueta <h1> representa el encabezado de mayor importancia, mientras que <h6> representa el nivel de encabezado menor.

¿Cuándo utilizarlas? Cuando es necesario organizar jerárquicamente títulos y subsecciones.

Ejemplo: 

<h1>ReneeWebCrew</h1>

<h2>Integrantes</h2>

<h3>Portafolio de proyectos</h3>

En ReneeWebCrew se utilizan encabezados para los nombres de las páginas, títulos de secciones, perfiles y contenidos de investigación.

Párrafos: <p>

La etiqueta <p> se utiliza para representar párrafos de texto.

¿Cuándo utilizarla? Cuando se desea presentar información escrita, explicaciones, descripciones o contenido textual.

Ejemplo: 

<p>
    ReneeWebCrew es un equipo de estudiantes
    de Ingeniería Civil Informática.
</p>

Esta etiqueta es utilizada ampliamente en el proyecto para las descripciones de integrantes, explicaciones de las investigaciones y textos de las diferentes secciones.

Enlaces: <a>

La etiqueta <a> permite crear enlaces hacia otras páginas, archivos, recursos o sitios web.

La dirección de destino se especifica mediante el atributo href.

¿Cuándo utilizarla? Cuando el usuario necesita desplazarse entre páginas o acceder a otro recurso.

Ejemplo utilizado en ReneeWebCrew: 

<a href="integrantes.html">
    👥 Integrantes
</a>

Esta etiqueta permite navegar desde la página principal hacia la página de integrantes.

Imágenes: <img>

La etiqueta <img> permite insertar una imagen dentro de una página HTML.

El atributo src indica la ubicación del archivo, mientras que alt proporciona una descripción alternativa.

¿Cuándo utilizarla? Cuando es necesario incorporar fotografías, logotipos, avatares, diagramas u otras imágenes.

Ejemplo utilizado en ReneeWebCrew: 

<img
    src="../img/logo.png"
    alt="Logo de ReneeWebCrew"
    class="avatar"
>

El sitio utiliza imágenes para el logo del equipo, fotografías de integrantes y logos de diferentes tecnologías.

Listas: <ul>, <ol> y <li>

HTML permite crear listas ordenadas y no ordenadas.

Lista no ordenada: <ul>

Se utiliza cuando el orden de los elementos no es relevante. 

<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>Bootstrap</li>

</ul>

Lista ordenada: <ol>

Se utiliza cuando los elementos deben seguir una secuencia o un orden determinado. 

<ol>

    <li>Instalar Docker Desktop</li>
    <li>Construir la imagen</li>
    <li>Ejecutar el contenedor</li>

</ol>

Elemento de lista: <li>

Cada elemento incluido dentro de una lista se representa utilizando <li>.

En ReneeWebCrew las listas se utilizan, por ejemplo, para representar fortalezas del equipo y enumerar diferentes contenidos de investigación.

Contenedores: <div>

La etiqueta <div> es un contenedor genérico utilizado para agrupar diferentes elementos HTML.

¿Cuándo utilizarla? Cuando se necesita agrupar elementos para organizarlos, aplicar estilos o trabajar con una estructura de diseño.

Ejemplo utilizado con Bootstrap: 

<div class="container-fluid">

    <div class="row">

        Contenido

    </div>

</div>

Esta estructura es utilizada en diferentes páginas de ReneeWebCrew para organizar las columnas de Bootstrap.

Elementos en línea: <span>

La etiqueta <span> es un contenedor en línea utilizado para agrupar una pequeña parte del contenido.

¿Cuándo utilizarla? Cuando se desea aplicar un estilo o identificar una parte específica de un texto sin generar un bloque nuevo.

Ejemplo: 

<span class="chip">
    Python
</span>

En los perfiles del equipo se utilizan elementos <span> con la clase chip para representar lenguajes, intereses, herramientas y tecnologías.

Diferencia entre <div> y <span>

Ambos elementos sirven para agrupar contenido, pero tienen comportamientos diferentes.

<div>: es un elemento de bloque y normalmente se utiliza para agrupar secciones o estructuras completas.

<span>: es un elemento en línea y se utiliza para agrupar una parte pequeña del contenido.

Ejemplo: 

<div class="perfil">

    Lenguajes:

    <span class="chip">Python</span>
    <span class="chip">Java</span>

</div>
Tablas: <table>

La etiqueta <table> permite representar información organizada en filas y columnas.

Habitualmente se combina con otras etiquetas como:

  • <thead>: encabezado de la tabla.
  • <tbody>: cuerpo de la tabla.
  • <tr>: fila.
  • <th>: celda de encabezado.
  • <td>: celda de datos.

¿Cuándo utilizarla? Cuando la información posee una relación clara entre filas y columnas.

Ejemplo: 

<table>

    <thead>

        <tr>
            <th>Tecnología</th>
            <th>Uso</th>
        </tr>

    </thead>


    <tbody>

        <tr>
            <td>HTML</td>
            <td>Estructura</td>
        </tr>

        <tr>
            <td>CSS</td>
            <td>Presentación</td>
        </tr>

    </tbody>

</table>

En ReneeWebCrew se utilizan tablas en algunas páginas de investigación para presentar información resumida y comparativa.

Formularios: <form>

La etiqueta <form> se utiliza para agrupar controles que permiten ingresar o enviar información.

¿Cuándo utilizarla? Cuando la página necesita recibir información del usuario.

Dentro de un formulario pueden utilizarse elementos como <label>, <input> y <button>.

Ejemplo: 

<form>

    <label for="nombre">
        Nombre:
    </label>

    <input
        type="text"
        id="nombre"
    >

    <button type="submit">
        Enviar
    </button>

</form>
Etiquetas de formulario: <label>

La etiqueta <label> permite proporcionar una descripción a un campo de formulario.

El atributo for puede relacionarse con el id de un <input>.

Ejemplo: 

<label for="spotify-link">
    Enlace de Spotify:
</label>
Campos de entrada: <input>

La etiqueta <input> permite que el usuario introduzca información.

Existen distintos tipos de input, por ejemplo texto, contraseña, correo electrónico, números y otros.

¿Cuándo utilizarla? Cuando se necesita recibir un dato ingresado por el usuario.

Ejemplo existente en la página principal: 

<input
    type="text"
    id="spotify-link-input"
    placeholder="Pega aquí el link de Spotify..."
>

ReneeWebCrew utiliza un campo de texto para que el usuario pueda ingresar un enlace de Spotify en la sección "Canción del día".

Botones: <button>

La etiqueta <button> permite crear un botón que puede activar una acción.

¿Cuándo utilizarla? Cuando el usuario debe ejecutar una acción, enviar información o activar alguna funcionalidad.

Ejemplo existente en ReneeWebCrew: 

<button onclick="actualizarCancion()">

    🎧 Actualizar canción

</button>

Este botón se utiliza en la página principal para actualizar el contenido de la sección "Canción del día".

Ejemplo combinando varias etiquetas HTML

El siguiente ejemplo reúne algunos de los elementos explicados anteriormente: 

<div class="integrante">

    <h2>
        Nombre del integrante
    </h2>

    <img
        src="../img/integrante.jpg"
        alt="Fotografía del integrante"
    >

    <p>
        Estudiante de Ingeniería Civil Informática.
    </p>

    <ul>

        <li>Python</li>
        <li>PostgreSQL</li>
        <li>Docker</li>

    </ul>

    <a href="perfil.html">
        Ver perfil
    </a>

</div>

En este ejemplo, <div> agrupa el contenido, <h2> representa el nombre, <img> incorpora una imagen, <p> contiene una descripción, <ul> organiza una lista y <a> permite acceder al perfil.

Ventajas de HTML
  • Simplicidad: posee una sintaxis relativamente sencilla que facilita su aprendizaje.
  • Compatibilidad: HTML es compatible con los principales navegadores web.
  • Gratuito y estandarizado: se trata de un estándar abierto utilizado ampliamente para construir páginas web.
  • Flexibilidad: puede combinarse con tecnologías como CSS, Bootstrap y otras herramientas para crear interfaces más completas.
Limitaciones de HTML

HTML se utiliza principalmente para definir el contenido y la estructura de una página, por lo que presenta limitaciones respecto al diseño visual.

Para controlar colores, posiciones, tamaños, márgenes y otros aspectos visuales es necesario complementarlo con CSS.

Además, HTML por sí solo permite construir principalmente contenido estático. Las funcionalidades más avanzadas necesitan ser complementadas con otras tecnologías.

Resumen

HTML constituye la estructura fundamental del sitio ReneeWebCrew.

Las diferentes etiquetas permiten representar títulos, textos, imágenes, enlaces, listas, contenedores, tablas y elementos de entrada para organizar el contenido de manera comprensible.

Posteriormente, HTML se complementa con CSS para definir la apariencia visual y con Bootstrap para organizar algunos elementos mediante su sistema de grillas y componentes.
