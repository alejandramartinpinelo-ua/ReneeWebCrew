🛠️ Herramientas utilizadas para coordinar el trabajo

Para la gestión y desarrollo del proyecto, el equipo utilizó un ecosistema de herramientas digitales enfocadas en la comunicación fluida y el control de versiones: ✦ GitHub: Utilizado para el control de versiones del código fuente, permitiendo integrar cambios, gestionar ramas de trabajo y mantener un registro claro del avance del proyecto. ✦ WhatsApp: Canal principal para la comunicación diaria, resolución rápida de dudas y avisos operativos inmediatos. ✦ Discord: Plataforma empleada para reuniones virtuales, sesiones de trabajo colaborativo en vivo y coordinación de tareas mediante la pantalla compartida.

⚠️ Dificultades encontradas durante el desarrollo

Durante el transcurso del proyecto, el equipo enfrentó diversos desafíos técnicos y de coordinación que pusieron a prueba nuestra capacidad de resolución de problemas: ✦ Conflictos al fusionar ramas en Git: Al trabajar simultáneamente en diferentes secciones del código, se generaron conflictos al intentar integrar las ramas en el repositorio principal de GitHub. ✦ Incompatibilidad de rutas de archivos: Se presentaron fallas al cargar archivos estáticos (imágenes, hojas de estilo) debido al uso de rutas absolutas o diferencias en el manejo de mayúsculas y minúsculas entre los sistemas operativos de los integrantes y el entorno del contenedor. ✦ Coordinación de tareas y trabajo en paralelo: Sincronizar el ritmo de avance de cada integrante para evitar sobreposición de trabajo o esperas innecesarias antes de integrar avances.

✅ Soluciones aplicadas

✦ Flujo de trabajo estructurado en Git: Establecimos la convención de trabajar en ramas individuales y realizar revisiones de código y resoluciones de conflictos en conjunto mediante llamadas en Discord. ✦ Estandarización de rutas relativas: Revisamos y corregimos la estructura de carpetas para utilizar exclusivamente rutas relativas en el HTML y CSS, asegurando que los recursos se cargaran correctamente. ✦ Comunicación continua y reasignación de tareas: Utilizamos WhatsApp y Discord para mantener actualizado el estado del trabajo de cada uno, aclarando dudas al instante y dividiendo las tareas en módulos independientes para optimizar el desarrollo en paralelo.

📚 Aprendizajes sobre HTML, CSS, Bootstrap, Docker y Nginx

HTML: ✦ CSS y Bootstrap: Aprendimos a diseñar interfaces atractivas y adaptables a distintos dispositivos (responsive design) utilizando el sistema de grillas, utilidades y componentes prediseñados de Bootstrap, complementados con reglas CSS personalizadas. ✦ Docker: Experimentamos con la virtualización a nivel de sistema operativo, aprendiendo a crear imágenes ligeras mediante Dockerfile y a ejecutar el proyecto dentro de contenedores aislados para garantizar un entorno de ejecución uniforme. ✦ Nginx: Entendimos el rol de un servidor web eficiente para procesar peticiones HTTP, entregar los archivos estáticos de la aplicación (HTML/CSS/JS) y gestionar de manera optimizada el tráfico del sitio dentro de la arquitectura con Docker.

🤝 Importancia de la colaboración y organización del equipo

✦ La colaboración activa y la buena organización fueron fundamentales para el éxito de este proyecto. A lo largo del proceso surgieron diversas dificultades y desafíos técnicos; sin embargo, mediante la aclaración oportuna de la información y una coordinación fluida entre todos, logramos resolver cada inconveniente de manera efectiva. Mantener una comunicación constante nos permitió superar los bloqueos a tiempo, evitar la duplicación de esfuerzos y asegurar que cada miembro aportara según sus fortalezas. Asimismo, definir responsabilidades claras desde el principio facilitó el cumplimiento de las entregas en las fechas estimadas, demostrando que una buena coordinación entre los desarrolladores impacta directamente en la calidad y estabilidad del producto final.
