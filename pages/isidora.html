✦ Portafolio de proyectos

ReneeWebCrew — Mini sitio web informativo | En desarrollo

Nombre del proyecto: ReneeWebCrew — Mini sitio web informativo del equipo.

Propósito: desarrollar una plataforma web estática que permita presentar a los integrantes del equipo, sus conocimientos, proyectos y las investigaciones realizadas durante el laboratorio.

Tecnologías utilizadas: HTML, CSS, Bootstrap, GitHub, Docker y Nginx.

Principales características: sitio desarrollado de manera colaborativa mediante GitHub, compuesto por una página principal, perfiles individuales, páginas de investigación y navegación entre las diferentes secciones.

Mi participación está orientada al apoyo en la creación y organización visual de páginas, revisión de contenido, estructura HTML y adaptación de elementos Front-End.

Estado: En desarrollo.

Sistema de Gestión para Biblioteca Universitaria | Finalizado

Nombre del proyecto: Sistema de Gestión para Biblioteca Universitaria.

Propósito: diseñar un sistema académico que permitiera organizar información relacionada con estudiantes, libros, préstamos y devoluciones dentro de una biblioteca.

Tecnologías utilizadas: Java, PostgreSQL, SQL y NetBeans.

Principales características: registro de libros y estudiantes, gestión de préstamos, control de devoluciones y almacenamiento de información mediante una base de datos relacional.

El proyecto permitió aplicar conceptos de programación orientada a objetos, estructuras de datos y conexión entre una aplicación y una base de datos.

Estado: Finalizado.

Prototipo de Aplicación para Organización Académica | Idea

Nombre del proyecto: Prototipo de Aplicación para Organización Académica.

Propósito: diseñar una propuesta de aplicación orientada a estudiantes para organizar evaluaciones, tareas, horarios y fechas importantes dentro de un mismo espacio digital.

Tecnologías consideradas: HTML, CSS, Bootstrap, JavaScript y PostgreSQL.

Principales características: calendario de evaluaciones, registro de tareas, organización por asignaturas, recordatorios visuales y una interfaz adaptable a dispositivos móviles.

El proyecto busca aplicar principios de diseño de interfaces y experiencia de usuario para facilitar la organización de actividades académicas.

Estado: Idea.
