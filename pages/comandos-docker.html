⌨️ Comandos Docker

Comandos fundamentales para administrar imágenes y contenedores ✦

✦ Comandos de uso frecuente

Docker dispone de diferentes comandos que permiten consultar la instalación, administrar imágenes, crear y ejecutar contenedores, detenerlos, eliminarlos y revisar su funcionamiento.

A continuación se presentan los principales comandos utilizados durante el desarrollo y administración de contenedores. Para cada uno se indica su sintaxis general, descripción, un ejemplo y el resultado esperado o situación en la que puede utilizarse.

✦ Principales comandos Docker

docker --version

Uso principal: consultar la versión de Docker instalada.

Sintaxis general: 

docker --version

Descripción: consulta y muestra la versión exacta de Docker instalada en el sistema.

Ejemplo de uso: 

docker --version

Resultado esperado: Docker muestra por consola la versión instalada, por ejemplo: 

Docker version 24.0.5

Este comando puede utilizarse al comenzar a trabajar para comprobar que Docker se encuentra instalado correctamente.

docker run hello-world

Uso principal: ejecutar una imagen de prueba.

Sintaxis: 

docker run hello-world

Descripción: ejecuta la imagen oficial hello-world para comprobar que Docker se encuentra correctamente instalado y funcionando.

Ejemplo de uso: 

docker run hello-world

Resultado esperado: Docker busca la imagen hello-world en el equipo. Si no se encuentra disponible localmente, la descarga y crea automáticamente un contenedor.

Finalmente se muestra el mensaje: 

Hello from Docker!
This message shows that your installation appears to be working correctly.

El contenedor finaliza automáticamente después de mostrar el mensaje de comprobación.

docker images

Uso principal: listar imágenes almacenadas localmente.

Sintaxis general: 

docker images [OPCIONES]

Descripción: lista las imágenes de Docker que han sido descargadas o construidas en el almacenamiento local.

Ejemplo de uso: 

docker images

Resultado esperado: se muestra una tabla que contiene información como el repositorio, etiqueta o tag, ID de la imagen, fecha de creación y tamaño.

Puede utilizarse para comprobar si una imagen determinada ya se encuentra disponible en el computador.

docker ps

Uso principal: mostrar los contenedores actualmente en ejecución.

Sintaxis general: 

docker ps [OPCIONES]

Descripción: muestra un listado de los contenedores que se encuentran funcionando actualmente.

Ejemplo de uso: 

docker ps

Resultado esperado: se presenta información como el ID del contenedor, la imagen utilizada, el comando ejecutado, el estado y los puertos expuestos.

Es útil para supervisar qué servicios o contenedores se encuentran activos.

docker ps -a

Uso principal: mostrar todos los contenedores.

Sintaxis: 

docker ps -a

Descripción: muestra todos los contenedores existentes en el sistema local, incluyendo los que están en ejecución y los que se encuentran detenidos.

Ejemplo de uso: 

docker ps -a

Resultado esperado: se muestra el historial de contenedores creados.

Puede utilizarse para encontrar el ID o nombre de un contenedor que se haya detenido y posteriormente revisar sus registros o eliminarlo.

docker build

Uso principal: construir una imagen desde un Dockerfile.

Sintaxis general: 

docker build [OPCIONES] RUTA

Descripción: construye una nueva imagen Docker utilizando las instrucciones definidas dentro de un archivo Dockerfile.

Ejemplo utilizado en el laboratorio: 

docker build -t mi-web-html .

Resultado esperado: Docker procesa las instrucciones del Dockerfile, descarga las dependencias necesarias y genera una nueva imagen.

En el laboratorio, este comando permite construir la imagen que posteriormente contiene y publica el sitio web.

docker run

Uso principal: crear y ejecutar un nuevo contenedor.

Sintaxis general: 

docker run [OPCIONES] IMAGEN [COMANDO]

Descripción: crea un contenedor nuevo a partir de una imagen especificada y posteriormente lo ejecuta.

Ejemplo utilizado en el laboratorio: 

docker run -d -p 8080:80 --name mi-web-container mi-web-html

Resultado esperado: Docker crea el contenedor a partir de la imagen mi-web-html y lo mantiene ejecutándose en segundo plano.

En este ejemplo también se conecta el puerto 8080 del computador con el puerto 80 utilizado dentro del contenedor.

docker stop

Uso principal: detener un contenedor.

Sintaxis general: 

docker stop CONTENEDOR

Descripción: detiene de forma segura uno o más contenedores que se encuentran actualmente en ejecución.

Ejemplo utilizado en el laboratorio: 

docker stop mi-web-container

Resultado esperado: el contenedor finaliza sus procesos y pasa al estado Exited.

Puede utilizarse cuando se desea detener temporalmente un servicio sin eliminar el contenedor.

docker start

Uso principal: iniciar un contenedor detenido.

Sintaxis general: 

docker start CONTENEDOR

Descripción: inicia nuevamente uno o más contenedores que habían sido detenidos anteriormente.

Ejemplo de uso: 

docker start mi_contenedor

Resultado esperado: el contenedor reanuda su funcionamiento manteniendo la configuración con la cual había sido creado.

docker rm

Uso principal: eliminar un contenedor.

Sintaxis general: 

docker rm CONTENEDOR

Descripción: elimina definitivamente un contenedor del sistema. El contenedor debe encontrarse detenido antes de poder eliminarlo.

Ejemplo utilizado en el laboratorio: 

docker rm mi-web-container

Resultado esperado: el contenedor desaparece del registro local, liberando el espacio asociado a él.

Este comando puede utilizarse para limpiar el entorno después de finalizar una prueba.

docker rmi

Uso principal: eliminar una imagen Docker.

Sintaxis general: 

docker rmi IMAGEN

Descripción: elimina una o más imágenes almacenadas localmente.

Ejemplo de uso: 

docker rmi ubuntu:latest

Resultado esperado: la imagen es eliminada del almacenamiento local, liberando espacio en disco.

Puede utilizarse cuando una imagen ha quedado obsoleta o cuando existen versiones antiguas que ya no son necesarias.

docker logs

Uso principal: consultar los registros de un contenedor.

Sintaxis general: 

docker logs CONTENEDOR

Descripción: muestra los registros generados por un contenedor, incluyendo su salida estándar y mensajes de error.

Ejemplo de uso: 

docker logs mi_contenedor_bd

Resultado esperado: se muestran líneas de texto correspondientes a los eventos registrados dentro del contenedor.

Este comando es especialmente útil para realizar tareas de depuración y analizar por qué un servicio o aplicación no inició correctamente.

docker exec

Uso principal: ejecutar comandos dentro de un contenedor.

Sintaxis general: 

docker exec [OPCIONES] CONTENEDOR COMANDO

Descripción: permite ejecutar un comando adicional dentro de un contenedor que ya se encuentra funcionando.

Ejemplo de uso: 

docker exec -it mi_contenedor bash

Resultado esperado: se abre una terminal interactiva bash dentro del contenedor.

Puede utilizarse para inspeccionar archivos, revisar configuraciones o ejecutar comandos directamente dentro del entorno del contenedor.
