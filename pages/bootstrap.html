Componentes reutilizables y diseño responsivo ✦

✦ ¿Qué es Bootstrap?

Bootstrap es un framework de código abierto orientado al desarrollo de interfaces de usuario para sitios web.

El framework incorpora diferentes estilos, herramientas y componentes prediseñados que pueden utilizarse mediante clases CSS directamente dentro de los documentos HTML.

Entre estos componentes se encuentran botones, menús, desplegables y otros elementos que facilitan la construcción de interfaces web.

Algunos componentes también necesitan JavaScript para funcionar, pero Bootstrap proporciona estas funcionalidades dentro del propio framework.

✦ Contenidos

¿Para qué sirve Bootstrap?

Bootstrap permite construir interfaces web de manera más rápida utilizando una biblioteca de componentes y estilos previamente definidos.

En lugar de programar desde cero todos los elementos visuales, el desarrollador puede utilizar las clases que proporciona Bootstrap directamente en el código HTML.

Esto facilita el desarrollo de páginas web, especialmente cuando se necesitan estructuras organizadas, componentes reutilizables y diseños adaptables a diferentes tamaños de pantalla.

Ventajas de utilizar un framework CSS

Utilizar un framework CSS como Bootstrap permite disponer de una base de estilos, componentes y herramientas que simplifican el desarrollo Front-End.

Entre sus principales ventajas se encuentran:

  • Desarrollo estable: Bootstrap es un framework maduro que ofrece herramientas ampliamente utilizadas en el desarrollo Front-End.
  • Diseño responsivo: sus componentes pueden adaptarse a diferentes tamaños de pantalla y dispositivos.
  • Desarrollo más rápido: permite utilizar clases y componentes existentes en lugar de desarrollar todos los estilos desde cero.
  • Variedad de componentes: dispone de una biblioteca con botones, desplegables, elementos de navegación y diferentes utilidades de diseño.
  • Documentación y comunidad: cuenta con una amplia documentación y una comunidad que facilita encontrar información y soluciones a problemas frecuentes.
Consistencia visual

Los componentes de Bootstrap utilizan un esquema de diseño común, permitiendo mantener cierta consistencia visual entre los diferentes elementos de una interfaz.

Además, Bootstrap incorpora utilidades que ayudan a controlar márgenes, espacios, alineaciones y la distribución del contenido.

En ReneeWebCrew, Bootstrap se combina con hojas de estilo CSS propias. De esta manera se aprovecha la organización que proporciona el framework sin perder la identidad visual personalizada del equipo.

Diseño responsivo

Un diseño responsivo permite que una página web adapte automáticamente su organización según el tamaño de la pantalla desde la cual se está visualizando.

Bootstrap fue desarrollado siguiendo una filosofía conocida como mobile first. Esto significa que sus herramientas consideran primero dispositivos de pantallas pequeñas y luego permiten adaptar el diseño para tablets, computadores portátiles y monitores de mayor tamaño.

Esto resulta especialmente útil para ReneeWebCrew, ya que el laboratorio exige que el sitio sea legible y adaptable tanto a computadores como a teléfonos móviles.

Sistema de grillas: container, row y col

Bootstrap utiliza un sistema de grillas para organizar el contenido de una página mediante filas y columnas.

Entre las clases principales utilizadas se encuentran:

container o container-fluid: contiene la estructura general de la página.

row: crea una fila donde posteriormente se ubican las diferentes columnas.

col: permite dividir la fila en columnas.

En ReneeWebCrew, la página principal utiliza esta estructura para dividir la interfaz en una barra lateral, un contenido central y una columna derecha. 

<div class="container-fluid">

    <div class="row">

        <aside class="col-lg-2">
            Barra lateral
        </aside>

        <main class="col-lg-7">
            Contenido principal
        </main>

        <aside class="col-lg-3">
            Contenido adicional
        </aside>

    </div>

</div>

En este ejemplo, cuando la pantalla tiene un tamaño grande, Bootstrap distribuye el espacio utilizando las clases col-lg-2, col-lg-7 y col-lg-3.

El sistema de Bootstrap trabaja con una división de doce columnas. En este caso: 

2 + 7 + 3 = 12

De esta manera se utiliza todo el ancho disponible de la fila.

Columnas adaptables

Bootstrap permite definir diferentes comportamientos dependiendo del tamaño de pantalla.

Por ejemplo, en la página principal del proyecto se utiliza: 

<div class="col-md-6">

    <section class="bloque">

        Contenido

    </section>

</div>

La clase col-md-6 permite que el elemento utilice seis columnas del sistema de doce cuando se encuentra en una pantalla mediana o superior.

Esto permite colocar dos bloques de seis columnas en una misma fila.

Componentes reutilizables

Una de las principales características de Bootstrap es su biblioteca de componentes reutilizables.

Estos componentes permiten incorporar elementos que ya poseen una estructura y comportamiento definidos, reduciendo la cantidad de código que debe desarrollarse manualmente.

Entre los componentes disponibles se pueden encontrar botones, menús, desplegables y otros elementos de interfaz.

En ReneeWebCrew se utiliza, por ejemplo, un componente desplegable para acceder a diferentes secciones del sitio. 

<div class="dropdown">

    <button
        class="btn dropdown-toggle"
        data-bs-toggle="dropdown">

        Ver secciones

    </button>


    <ul class="dropdown-menu">

        <li>
            <a class="dropdown-item" href="investigacion.html">
                Investigación
            </a>
        </li>

    </ul>

</div>
Botones de Bootstrap

Bootstrap permite aplicar estilos predeterminados a botones mediante la clase btn.

Por ejemplo: 

<button class="btn btn-primary">
    Ver información
</button>

También pueden combinarse las clases de Bootstrap con estilos propios para adaptar los botones a la identidad visual del proyecto.

Bootstrap vs CSS personalizado

Bootstrap y CSS personalizado pueden utilizarse de manera complementaria.

Bootstrap resulta útil cuando se necesita desarrollar rápidamente una estructura responsiva o utilizar componentes que ya están preparados.

CSS personalizado permite controlar con mayor detalle la identidad visual del sitio, como colores, tamaños, tipografías, bordes, animaciones y otros aspectos específicos del diseño.

En ReneeWebCrew se utilizan ambas alternativas: Bootstrap se emplea principalmente para la organización mediante grillas y algunos componentes, mientras que los archivos CSS propios permiten mantener el diseño visual característico del equipo.

¿Cuándo utilizar Bootstrap?

Bootstrap es especialmente útil en proyectos donde se desea desarrollar una interfaz de manera rápida utilizando componentes ya preparados y un sistema responsivo.

Puede ser adecuado cuando se necesita:

  • Desarrollar una interfaz en poco tiempo.
  • Adaptar el sitio a distintos dispositivos.
  • Utilizar componentes reutilizables.
  • Mantener una estructura visual consistente.
¿Cuándo puede no ser conveniente?

Bootstrap puede no ser la mejor alternativa para proyectos que requieren un nivel muy elevado de personalización visual, ya que sus componentes poseen estilos reconocibles que deben ser modificados para lograr diseños completamente diferentes.

También puede ser menos conveniente cuando la optimización y el tamaño de los recursos son una prioridad, debido a que el framework puede incluir estilos o funcionalidades que una página específica no utiliza.

Compatibilidad entre navegadores

Otra ventaja de Bootstrap es que sus componentes están diseñados para funcionar correctamente en los navegadores utilizados habitualmente por los usuarios.

Entre ellos se encuentran Google Chrome, Microsoft Edge, Apple Safari, Mozilla Firefox y navegadores móviles de dispositivos iOS y Android.

Bootstrap utilizado en ReneeWebCrew

En el proyecto ReneeWebCrew Bootstrap se incorpora mediante CDN.

La hoja de estilos se enlaza utilizando: 

<link
    href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
    rel="stylesheet"
>

Para los componentes que utilizan JavaScript, también se incorpora Bootstrap Bundle: 

<script
    src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js">
</script>

Entre las clases y componentes utilizados actualmente por el equipo se encuentran:

  • container-fluid: contenedor principal de algunas páginas.
  • row: organización del contenido mediante filas.
  • col-lg-*: distribución de las columnas principales.
  • col-md-6: creación de bloques adaptables.
  • btn: estilos de botones.
  • dropdown: menú desplegable utilizado en la página principal.
  • dropdown-menu: contiene las opciones del menú desplegable.
  • dropdown-item: representa cada enlace del desplegable.
  • mt-4: utilidad para aplicar margen superior.
  • g-4: permite controlar el espacio entre columnas.
Resumen

Bootstrap facilita el desarrollo de interfaces web mediante clases, componentes y un sistema de grillas que permite organizar el contenido de manera responsiva.

En ReneeWebCrew se utiliza junto con CSS personalizado. Bootstrap ayuda principalmente a organizar la estructura y algunos componentes, mientras que las hojas de estilo propias permiten mantener la identidad visual del equipo.
