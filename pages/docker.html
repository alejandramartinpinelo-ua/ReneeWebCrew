🐳 Instalación y ejecución de Docker

Preparando el entorno para ejecutar nuestro sitio mediante contenedores ✦

✦ ¿Qué es Docker Desktop?

Docker Desktop es una aplicación que permite utilizar Docker desde sistemas operativos de escritorio como Windows.

A través de Docker Desktop es posible crear, ejecutar y administrar imágenes y contenedores desde el computador de forma local.

En este laboratorio utilizamos Docker Desktop para comprobar inicialmente el funcionamiento de Docker mediante la imagen hello-world y posteriormente ejecutar el sitio web ReneeWebCrew dentro de un contenedor.

En Windows, la instalación utilizada durante el laboratorio trabaja con WSL2 (Windows Subsystem for Linux 2), permitiendo disponer de un entorno Linux necesario para la ejecución de los contenedores.

✦ Instalación y prueba de Docker

Requisitos básicos de instalación

Antes de instalar Docker Desktop es necesario contar con un computador compatible con Windows y tener disponible el entorno necesario para ejecutar Docker.

Para el procedimiento realizado en este laboratorio se consideran los siguientes elementos:

  • Sistema operativo Windows compatible.
  • WSL2 disponible para ejecutar el entorno Linux.
  • Virtualización habilitada cuando sea requerida por el sistema.
  • Conexión a Internet para descargar Docker Desktop y las imágenes utilizadas.
  • Permisos para instalar aplicaciones en el computador.

Durante la instalación realizada por el equipo se utilizó la alternativa recomendada de instalación por usuario junto con WSL2.

1. Descarga de Docker Desktop

El primer paso consiste en ingresar al sitio oficial de Docker y descargar Docker Desktop para el sistema operativo utilizado.

Dentro del sitio de Docker se selecciona la versión correspondiente a Windows y se descarga el instalador.

Una vez completada la descarga se obtiene el archivo de instalación de Docker Desktop, que permitirá comenzar con la configuración del programa.

2. Instalación de Docker Desktop

Después de descargar el instalador se ejecuta Docker Desktop Installer para comenzar con la instalación.

Durante el procedimiento realizado en el laboratorio se seleccionó: 

Per-user installation (Recommended)

Esta alternativa utiliza WSL2 como parte del entorno necesario para ejecutar los contenedores Linux desde Windows.

Después se continúa con los pasos indicados por el asistente hasta finalizar la instalación.

Una vez terminado el proceso, Docker Desktop puede ejecutarse desde el menú de inicio de Windows.

3. Primer arranque de Docker Desktop

Al finalizar la instalación se abre Docker Desktop y se acepta el acuerdo de servicio correspondiente.

Posteriormente Docker puede solicitar iniciar sesión o crear una cuenta para utilizar servicios en línea como Docker Hub.

Para el desarrollo de este laboratorio no fue necesario crear una cuenta, ya que el trabajo se realizó de manera local.

Por esta razón, la ventana de inicio de sesión pudo omitirse utilizando la opción Skip.

4. Prueba rápida de Docker

Una vez iniciado Docker Desktop se abre una terminal, CMD o PowerShell en Windows.

Para comprobar que Docker se encuentra instalado y funcionando correctamente se ejecuta: 

docker run hello-world

Este comando ejecuta la imagen oficial hello-world, utilizada específicamente para comprobar el funcionamiento de Docker.

¿Qué ocurre al ejecutar docker run hello-world?

Al ejecutar: 

docker run hello-world

Docker realiza automáticamente una serie de pasos.

1. Busca la imagen localmente

Docker comprueba primero si la imagen hello-world se encuentra almacenada en el computador.

Si todavía no ha sido descargada, la terminal informa que no se encuentra disponible de forma local.

2. Descarga la imagen

Docker obtiene automáticamente la imagen oficial de hello-world.

3. Crea el contenedor

Una vez obtenida la imagen, Docker crea un contenedor basado en ella.

4. Ejecuta el contenedor

El contenedor ejecuta su proceso y muestra un mensaje de comprobación. 

Hello from Docker!

Este mensaje confirma que Docker puede descargar imágenes, crear contenedores y ejecutarlos correctamente.

5. El contenedor finaliza

Después de mostrar el mensaje, hello-world termina automáticamente, debido a que solamente está diseñado para realizar esta prueba.

Evidencia: ejecución de hello-world

Durante el laboratorio se ejecutó correctamente: 

docker run hello-world

La terminal mostró el mensaje "Hello from Docker!", confirmando que Docker Desktop se encontraba instalado y funcionando correctamente.

Esta prueba también permitió verificar que Docker puede descargar una imagen, crear un contenedor y ejecutarlo sin inconvenientes.

Evidencia: Docker Desktop funcionando

Después de ejecutar hello-world, Docker Desktop permite visualizar el contenedor generado durante la prueba.

El contenedor aparece detenido una vez finalizada su ejecución, debido a que la imagen hello-world termina automáticamente después de mostrar el mensaje de comprobación.

Su presencia dentro de Docker Desktop confirma que el contenedor fue creado correctamente.

Comprobar los contenedores creados

También es posible consultar desde la terminal todos los contenedores existentes utilizando: 

docker ps -a

La opción -a permite mostrar tanto los contenedores que están funcionando como aquellos que ya se encuentran detenidos.

Debido a que hello-world finaliza después de ejecutar su prueba, el contenedor puede visualizarse en estado detenido.

¿Cómo se utiliza Docker en ReneeWebCrew?

Una vez comprobado el correcto funcionamiento de Docker mediante hello-world, el siguiente paso del laboratorio consiste en utilizar Docker para ejecutar el sitio web ReneeWebCrew.

Para esto se crea un archivo Dockerfile que utiliza Nginx como servidor web.

Posteriormente se construye una imagen Docker y se crea un contenedor que publica el sitio mediante el puerto 8080 del computador.

El sitio puede ser visualizado desde: 

http://localhost:8080

Este proceso se explica con mayor detalle en la sección de investigación dedicada a Nginx.

Resumen del proceso 
1. Descargar Docker Desktop.

2. Ejecutar el instalador.

3. Utilizar WSL2 en Windows.

4. Abrir Docker Desktop.

5. Omitir el inicio de sesión si no es necesario.

6. Abrir CMD, PowerShell o Terminal.

7. Ejecutar:

   docker run hello-world

8. Verificar el mensaje:

   Hello from Docker!

9. Comprobar el contenedor desde Docker Desktop.

10. Continuar con la construcción del sitio ReneeWebCrew.

Con esta prueba se confirma que Docker se encuentra correctamente instalado y preparado para construir y ejecutar los contenedores necesarios durante el desarrollo del laboratorio.
