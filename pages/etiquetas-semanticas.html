Etiquetas Semánticas de HTML

Las etiquetas semánticas permiten organizar el contenido indicando claramente la función de cada parte.

¿Qué son las etiquetas semánticas?

Las etiquetas semánticas son elementos de HTML que indican claramente el significado y función del contenido.

<header>

Representa el encabezado de una página o sección.

Uso en ReneeWebCrew: encabezados de las páginas y perfiles.

<nav>

Contiene enlaces que permiten navegar por el sitio.

Uso en ReneeWebCrew: barra lateral de navegación.

<main>

Contiene el contenido principal de una página.

Uso en ReneeWebCrew: contenido principal de las diferentes páginas.

<section>

Agrupa contenido relacionado.

Uso en ReneeWebCrew: perfiles, proyectos e información del equipo.

<article>

Representa contenido independiente.

Uso en ReneeWebCrew: paneles de información y proyectos.

<aside>

Contiene información complementaria.

Uso en ReneeWebCrew: barra lateral y columnas complementarias.

<footer>

Representa el pie de una página.

Puede contener información del autor, contacto u otros enlaces.

Ejemplo de estructura semántica

<header>
    <h1>ReneeWebCrew</h1>
</header>

<nav>
    <a href="indexxx.html">Inicio</a>
</nav>

<main>

    <section>

        <article>
            Contenido
        </article>

    </section>

</main>

<footer>
    ReneeWebCrew
</footer>
