Etiquetas Semánticas de HTML

Las etiquetas semánticas permiten organizar el contenido de una página web indicando claramente la función de cada parte.

Inicio Integrantes

¿Qué son las etiquetas semánticas?

Las etiquetas semánticas son elementos de HTML que indican claramente el significado y la función del contenido que contienen.

Su utilización permite crear páginas más ordenadas, comprensibles y fáciles de mantener.

<header>

La etiqueta <header> representa el encabezado de una página o de una sección.

Puede contener títulos, textos introductorios, logotipos u otros elementos relacionados con la presentación de la página.

Uso en ReneeWebCrew: se utiliza en las páginas de los integrantes para mostrar el nombre y el rol de cada integrante.

<nav>

La etiqueta <nav> se utiliza para contener enlaces de navegación.

Permite que el usuario pueda desplazarse entre las diferentes páginas o secciones de un sitio web.

Uso en ReneeWebCrew: se utiliza en la página principal para organizar los enlaces del menú de navegación.

<main>

La etiqueta <main> contiene el contenido principal de una página web.

Normalmente debe existir un solo elemento <main> dentro de cada página.

Uso en ReneeWebCrew: se utiliza para contener la información principal de la página de integrantes y de los perfiles individuales.

<section>

La etiqueta <section> permite agrupar contenido relacionado dentro de una página.

Cada sección puede representar un tema o una parte específica del contenido.

Uso en ReneeWebCrew: se utiliza para separar información como intereses, lenguajes de programación, bases de datos y portafolio.

<article>

La etiqueta <article> representa contenido independiente dentro de una página.

Puede utilizarse para noticias, publicaciones, tarjetas, proyectos u otros contenidos que tengan sentido por sí solos.

Uso en ReneeWebCrew: se utiliza para representar las tarjetas individuales de los integrantes y los proyectos de sus portafolios.

<aside>

La etiqueta <aside> contiene información complementaria relacionada con el contenido principal.

Puede utilizarse para barras laterales, información adicional, enlaces relacionados o actividades.

Uso en ReneeWebCrew: se utiliza en la página principal para las columnas laterales donde se muestran actividades e información complementaria.

<footer>

La etiqueta <footer> representa el pie de una página o de una sección.

Puede contener información del autor, datos de contacto, enlaces o información relacionada con el sitio.

Uso en ReneeWebCrew: se utiliza al final de esta página para identificar al equipo y la asignatura.

Ejemplo de estructura semántica

El siguiente ejemplo muestra una estructura básica utilizando las principales etiquetas semánticas: 

<header>
    <h1>ReneeWebCrew</h1>
</header>

<nav>
    <a href="indexxx.html">Inicio</a>
    <a href="integrantes.html">Integrantes</a>
</nav>

<main>

    <section>

        <h2>Integrantes</h2>

        <article>
            <h3>Nombre del integrante</h3>
            <p>Descripción del integrante</p>
        </article>

    </section>

    <aside>
        <p>Información complementaria</p>
    </aside>

</main>

<footer>
    <p>ReneeWebCrew</p>
</footer>

Uso de etiquetas en ReneeWebCrew

Etiqueta Propósito Uso en el sitio
<header> Representa un encabezado. Encabezados de páginas y perfiles.
<nav> Contiene enlaces de navegación. Menú de navegación del sitio.
<main> Contiene el contenido principal. Contenido principal de cada página.
<section> Agrupa contenidos relacionados. Intereses, lenguajes, bases de datos y portafolio.
<article> Representa contenido independiente. Tarjetas de integrantes y proyectos.
<aside> Contiene información complementaria. Columnas laterales de la página principal.
<footer> Representa el pie de página. Información final del sitio.
