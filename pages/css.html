Dando estilo y vida a la estructura ✦

✦ ¿Qué es CSS?

CSS significa Cascading Style Sheets, que en español se traduce como Hojas de Estilo en Cascada.

Es un lenguaje utilizado para definir la apariencia visual de los documentos HTML. Por medio de CSS es posible controlar elementos como colores, tamaños, tipografías, márgenes, bordes, posiciones, alineaciones y distribución de los componentes de una página web.

Mientras HTML permite crear y organizar el contenido, CSS permite determinar cómo se presenta ese contenido al usuario.

✦ Contenidos

Importancia de CSS en el desarrollo web

CSS es importante porque permite separar la estructura de una página de su presentación visual. De esta forma, el código HTML puede concentrarse en organizar el contenido mientras que los archivos CSS controlan su apariencia.

También permite reutilizar los mismos estilos en diferentes páginas, haciendo que el sitio mantenga una identidad visual coherente y facilitando su mantenimiento.

En ReneeWebCrew utilizamos CSS para mantener colores, tamaños, bordes, espacios, perfiles, menús, imágenes y otros elementos visuales de manera consistente.

Contenido, estructura y presentación

En una página web podemos distinguir tres conceptos principales:

Contenido: corresponde a la información que se desea mostrar al usuario, como textos, imágenes, nombres, proyectos y enlaces.

Estructura: corresponde a la forma en que el contenido se organiza utilizando HTML. Por ejemplo, mediante etiquetas como <header>, <nav>, <main>, <section> y <footer>.

Presentación: corresponde a la apariencia visual de esos elementos y se controla principalmente mediante CSS.

Por ejemplo, HTML puede crear un título utilizando: 

<h1>ReneeWebCrew</h1>

Y CSS puede definir su color y tamaño: 

h1 {
    color: #405F2A;
    font-size: 32px;
}
Formas de aplicar CSS

CSS puede incorporarse a una página HTML de tres formas principales: en línea, interna y externa.

CSS en línea

Se escribe directamente dentro de una etiqueta HTML mediante el atributo style. 

<p style="color: green;">
    Texto de ejemplo
</p>

Este método puede ser útil para aplicar un estilo muy específico, aunque no es recomendable utilizarlo constantemente porque dificulta la organización del código.

CSS interno

Se escribe dentro de una etiqueta <style> ubicada normalmente dentro del <head> del documento HTML. 

<style>

    p {
        color: green;
    }

</style>

Los estilos internos afectan únicamente al archivo HTML en el que fueron definidos.

CSS externo

Consiste en crear un archivo .css independiente y enlazarlo posteriormente desde el documento HTML mediante la etiqueta <link>. 

<link rel="stylesheet" href="../css/styles.css">

Esta es la forma utilizada principalmente en ReneeWebCrew, ya que permite compartir los mismos estilos entre diferentes páginas y mantener el código más ordenado.

Selectores básicos

Los selectores permiten indicar a qué elementos HTML se aplicará una determinada regla CSS.

Selector de etiqueta

Permite aplicar un estilo a todas las etiquetas HTML del mismo tipo. 

p {
    color: #405F2A;
}

En este ejemplo, todos los elementos <p> tendrán el color definido.

Selector de clase

Se utiliza colocando un punto . antes del nombre de la clase. 

.menu {
    padding: 20px;
}

Selector de identificador

Se utiliza colocando el símbolo # antes del identificador. 

#spotify-embed-container {
    width: 100%;
}
Clases e identificadores

Las clases y los identificadores permiten seleccionar elementos específicos de una página.

Una clase puede utilizarse en varios elementos diferentes. Se asigna utilizando el atributo class. 

<a href="integrantes.html" class="menu">
    Integrantes
</a>

En CSS se selecciona mediante un punto: 

.menu {
    text-align: center;
}

En cambio, un identificador se utiliza para reconocer un elemento específico y normalmente único dentro de la página. 

<div id="spotify-embed-container">
</div>

En CSS se selecciona utilizando el símbolo #: 

#spotify-embed-container {
    width: 100%;
}

En ReneeWebCrew utilizamos principalmente clases para aplicar estilos que pueden repetirse en diferentes elementos del sitio.

Modelo de caja

CSS considera a los elementos HTML como cajas. Cada una de estas cajas está compuesta por cuatro partes principales:

Contenido: corresponde al texto, imagen u otro elemento ubicado dentro de la caja.

Padding o relleno: es el espacio existente entre el contenido y el borde de la caja.

Border o borde: rodea el contenido y su relleno.

Margin o margen: corresponde al espacio exterior que separa la caja de otros elementos.

Un ejemplo de modelo de caja sería: 

.bloque {
    margin: 20px;
    border: 2px solid #AEBB8F;
    padding: 20px;
    background-color: #F8F0D7;
}

En este ejemplo, margin genera espacio exterior, border crea el borde y padding genera espacio entre el contenido y el borde.

Ejemplos de estilos aplicados en ReneeWebCrew

En nuestro sitio se utilizan diferentes clases CSS para crear una identidad visual común entre las páginas.

Ejemplo 1: barra lateral

La barra lateral se utiliza para mantener la navegación disponible y visualmente separada del contenido principal. 

.barra-lateral {
    padding: 20px;
}

Ejemplo 2: imágenes de integrantes

Las imágenes utilizan clases que permiten controlar su tamaño y presentación. 

.avatar-perfil {
    width: 150px;
    height: 150px;
    object-fit: cover;
    border-radius: 50%;
}

Ejemplo 3: tarjetas o paneles

En los perfiles del equipo se utilizan paneles y bloques para separar visualmente la información. 

.panel-perfil {
    padding: 20px;
    margin-bottom: 20px;
    border-radius: 15px;
}

Gracias al uso de CSS, las diferentes páginas de ReneeWebCrew pueden mantener colores, espacios, bordes y estilos similares, entregando una identidad visual coherente.

Resumen

CSS es una parte fundamental del desarrollo Front-End porque permite controlar la presentación de las páginas HTML.

Mediante selectores, clases, identificadores y propiedades es posible modificar prácticamente todos los aspectos visuales de una página web.

En ReneeWebCrew, CSS se utiliza junto con HTML y Bootstrap para construir una interfaz clara, organizada, coherente y adaptable.
