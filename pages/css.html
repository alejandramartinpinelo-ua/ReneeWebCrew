Investigación sobre CSS

Conoce qué es CSS, cómo se utiliza y cuál es su importancia dentro del desarrollo web.

¿Qué es CSS?

CSS significa Cascading Style Sheets o Hojas de Estilo en Cascada.

Es un lenguaje utilizado para definir la apariencia visual de una página web, permitiendo modificar colores, tamaños, márgenes, posiciones, fuentes y otros aspectos de presentación.

Importancia de CSS en el desarrollo web

CSS permite separar el contenido de una página de su presentación visual.

Gracias a CSS es posible mantener un diseño uniforme entre diferentes páginas, reutilizar estilos y adaptar el sitio a distintos tamaños de pantalla.

Contenido, estructura y presentación

Elemento Función
HTML Define el contenido y la estructura de la página web.
CSS Define la presentación y apariencia visual del contenido.
Bootstrap Facilita el diseño responsivo mediante estilos y componentes reutilizables.

Formas de aplicar CSS

CSS en línea

El estilo se escribe directamente dentro de una etiqueta HTML utilizando el atributo style. 

<p style="color: blue;">
    Texto azul
</p>

CSS interno

Los estilos se escriben dentro de la etiqueta <style> en el archivo HTML. 

<style>

    p {
        color: blue;
    }

</style>

CSS externo

Los estilos se escriben en un archivo CSS separado y luego se conectan con el documento HTML. 

<link rel="stylesheet"
      href="../css/styles.css">

En ReneeWebCrew se utiliza principalmente CSS externo para mantener los estilos organizados.

Selectores básicos

Los selectores permiten indicar qué elementos HTML recibirán determinados estilos.

Selector por etiqueta

p {
    color: green;
}

Este ejemplo aplica el color verde a todos los elementos <p>.

Selector por clase

.menu {
    background-color: green;
}

El punto . indica que se está seleccionando una clase.

Selector por identificador

#titulo {
    font-size: 30px;
}

El símbolo # permite seleccionar un elemento mediante su identificador.

Clases e identificadores

Una clase puede ser utilizada en varios elementos HTML. 

<a class="menu">
    Inicio
</a>

Un identificador debe utilizarse principalmente para identificar un elemento único. 

<h1 id="titulo">
    ReneeWebCrew
</h1>

Modelo de caja

En CSS todos los elementos pueden entenderse como una caja formada por cuatro partes principales:

Margin
Border
Padding
Contenido
  • Margin: espacio exterior del elemento.
  • Border: borde que rodea al elemento.
  • Padding: espacio entre el borde y el contenido.
  • Contenido: texto, imagen u otro elemento mostrado.

Ejemplos de CSS utilizados en ReneeWebCrew

En nuestro sitio utilizamos CSS para diseñar diferentes elementos de las páginas.

Barra lateral

.barra-lateral {
    background-color: var(--sage);
}

Botones del menú

.menu a {
    padding: 12px;
    border-radius: 10px;
    text-decoration: none;
}

Imágenes

.avatar {
    width: 140px;
    border-radius: 50%;
}

Estos estilos permiten mantener una identidad visual coherente en las diferentes páginas del proyecto.
