✦ Portafolio de proyectos

ReneeWebCrew — Desarrollo Web Colaborativo | En desarrollo

Nombre del proyecto: ReneeWebCrew — Desarrollo Web Colaborativo.

Propósito: diseñar y desarrollar una página web colaborativa como parte de un proyecto académico, creando una interfaz común para organizar información del grupo, tareas, noticias, fotografías y accesos rápidos.

Tecnologías utilizadas: HTML, CSS, Visual Studio Code, GitHub y Docker.

Principales características: proyecto desarrollado en equipo mediante un repositorio compartido en GitHub. Mi trabajo se centra principalmente en el desarrollo de la página principal y en la estructura de las páginas de integrantes.

El proyecto utiliza una organización separada de archivos HTML, hojas de estilo CSS e imágenes. La página principal incorpora diferentes apartados de navegación y elementos como tareas del día, feed de mensajes, noticias, fotografías, notificaciones y accesos rápidos.

El proyecto también me ha permitido aprender a trabajar con repositorios, commits, colaboradores y una estructura organizada de desarrollo web.

Estado: En desarrollo.

Modernización de una Plataforma de Gestión Logística | Finalizado

Nombre del proyecto: Modernización de una Plataforma de Gestión Logística.

Propósito: analizar los problemas de una empresa ficticia de logística y estudiar la modernización de su plataforma tecnológica ante el crecimiento de pedidos y operaciones digitales.

Tecnologías y conocimientos utilizados: arquitectura de software, análisis de sistemas, diseño de soluciones y documentación técnica.

Principales características: proyecto académico desarrollado en equipo para analizar la situación de una empresa que utiliza diferentes aplicaciones para gestionar clientes, pedidos, inventario, transporte, despachos y seguimiento.

El proyecto estudia los problemas derivados de mantener sistemas separados y plantea alternativas para mejorar la integración, mantenibilidad y evolución de la plataforma.

Su desarrollo permite aplicar conceptos relacionados con arquitectura de software, identificación de problemas de diseño y toma de decisiones técnicas.

Estado: Finalizado.

Laboratorios de Redes y Sistemas Linux | En desarrollo

Nombre del proyecto: Laboratorios de Redes y Sistemas Linux.

Propósito: configurar y analizar diferentes servicios y conceptos relacionados con sistemas operativos, redes de computadores y comunicación entre dispositivos.

Tecnologías utilizadas: Ubuntu Linux, VirtualBox, PuTTY, SSH, Docker, NAT, DNS y HTTP.

Principales características: conjunto de prácticas realizadas sobre máquinas virtuales Ubuntu para comprender de manera práctica el funcionamiento de redes y sistemas.

Durante los laboratorios he trabajado con comandos de Linux, configuración y comprobación de conectividad, direcciones IP, NAT, DNS, conexiones mediante SSH y pruebas de servicios HTTP.

También he utilizado Docker para comenzar a trabajar con contenedores y comprender cómo pueden utilizarse para ejecutar aplicaciones en entornos aislados.

Las prácticas se documentan mediante evidencias y grabaciones de los procedimientos realizados, lo que también requiere comprender y explicar el propósito de los comandos utilizados.

Estado: En desarrollo.
