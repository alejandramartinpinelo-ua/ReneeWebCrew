🌐 Nginx

Publicando nuestro sitio mediante Docker y Nginx ✦

✦ ¿Qué es Nginx?

Nginx es utilizado en este laboratorio como servidor web para publicar el sitio ReneeWebCrew dentro de un contenedor Docker.

Su función dentro del proyecto consiste en recibir las solicitudes realizadas desde el navegador y entregar los archivos que forman parte del sitio web.

En nuestro caso, Docker utiliza la imagen nginx:alpine como base del contenedor y copia el archivo HTML al directorio desde donde Nginx sirve las páginas web.

✦ Construcción y publicación con Nginx

Propósito de Nginx en ReneeWebCrew

El propósito de Nginx en este proyecto es actuar como el servidor web encargado de publicar el contenido HTML que se encuentra dentro del contenedor Docker.

De esta forma, el sitio puede ejecutarse en un entorno aislado y ser accedido desde el navegador mediante una dirección local.

El proceso general utilizado en el laboratorio es: 

Archivos del sitio
        ↓
Dockerfile
        ↓
Imagen Docker
        ↓
Contenedor
        ↓
Nginx
        ↓
http://localhost:8080

Nginx trabaja dentro del contenedor utilizando el puerto 80, mientras que Docker permite acceder desde el computador mediante el puerto 8080.

Dockerfile utilizado

El archivo Dockerfile contiene las instrucciones utilizadas por Docker para construir la imagen que posteriormente ejecutará Nginx.

El Dockerfile utilizado en la primera prueba del laboratorio contiene: 

# Usar la imagen oficial de nginx como servidor web
FROM nginx:alpine

# Copiar nuestra página HTML al directorio que nginx sirve por defecto
COPY index.html /usr/share/nginx/html/index.html

Este archivo se guarda con el nombre Dockerfile, sin extensión.

Instrucción FROM nginx:alpine

La primera instrucción del Dockerfile es: 

FROM nginx:alpine

La instrucción FROM indica qué imagen se utilizará como base para construir nuestra propia imagen Docker.

En este proyecto se utiliza nginx:alpine, que proporciona Nginx dentro de una imagen base utilizada posteriormente para servir la página web.

Instrucción COPY

La segunda instrucción utilizada es: 

COPY index.html /usr/share/nginx/html/index.html

La instrucción COPY copia el archivo index.html del proyecto hacia el directorio utilizado por Nginx para servir contenido web.

La ruta: 

/usr/share/nginx/html/

corresponde al directorio desde el cual Nginx entrega los archivos web dentro del contenedor.

Construcción de la imagen Docker

Una vez creado el archivo Dockerfile, se abre una terminal o CMD en la carpeta del proyecto.

El comando utilizado para construir la imagen es: 

docker build -t mi-web-html .

El comando docker build indica a Docker que debe construir una imagen.

La opción: 

-t mi-web-html

asigna el nombre mi-web-html a la imagen generada.

Finalmente, el punto . indica que Docker debe utilizar como contexto de construcción la carpeta actual.

Durante este proceso Docker descarga la imagen base nginx:alpine si todavía no se encuentra disponible y genera posteriormente la nueva imagen del proyecto.

Ejecución del contenedor

Una vez construida la imagen, se ejecuta el contenedor utilizando: 

docker run -d -p 8080:80 --name mi-web-container mi-web-html

Este comando crea y ejecuta un contenedor basado en la imagen mi-web-html.

Las opciones utilizadas tienen las siguientes funciones:

  • -d: ejecuta el contenedor en segundo plano, también denominado modo detached.
  • -p 8080:80: realiza el mapeo de puertos entre el computador y el contenedor.
  • --name mi-web-container: asigna el nombre mi-web-container al contenedor.
  • mi-web-html: corresponde al nombre de la imagen utilizada para crear el contenedor.
Mapeo de puertos 8080:80

Una parte fundamental del comando de ejecución corresponde a: 

-p 8080:80

Esta configuración relaciona el puerto 8080 del computador con el puerto 80 del contenedor. 

COMPUTADOR              CONTENEDOR

Puerto 8080    ───────► Puerto 80
                         │
                         ▼
                       Nginx

Nginx sirve el sitio utilizando el puerto 80 dentro del contenedor, mientras que el usuario accede desde el navegador mediante el puerto 8080 del computador.

Por esta razón, para visualizar el sitio se utiliza: 

http://localhost:8080
Acceso al sitio desde el navegador

Una vez que el contenedor se encuentra ejecutándose, se abre un navegador web y se introduce la siguiente dirección: 

http://localhost:8080

Al acceder a esta dirección, la página web debe visualizarse correctamente.

Este resultado confirma que:

  • La imagen Docker fue construida correctamente.
  • El contenedor se encuentra funcionando.
  • El mapeo de puertos está configurado.
  • Nginx está sirviendo el archivo HTML.
Detener el contenedor

Para detener el contenedor utilizado en el laboratorio se ejecuta: 

docker stop mi-web-container

Este comando detiene el contenedor sin eliminarlo.

Eliminar el contenedor

Si se desea eliminar el contenedor después de detenerlo, se utiliza: 

docker rm mi-web-container

Este comando elimina el contenedor del entorno local.

Evidencia: construcción de la imagen

Durante la construcción de la imagen se ejecutó el comando: 

docker build -t mi-web-html .

La terminal mostró el procesamiento de las instrucciones del Dockerfile y la creación correcta de la imagen.

Evidencia: contenedor en ejecución

El comando de ejecución fue procesado correctamente y Docker devolvió el identificador del contenedor creado.

Esto confirma que el contenedor basado en la imagen mi-web-html fue iniciado.

Evidencia: sitio funcionando en localhost:8080

Finalmente, se accede desde el navegador a: 

http://localhost:8080

La correcta visualización de la página confirma que la imagen fue construida y ejecutada correctamente y que Nginx se encuentra sirviendo el contenido web desde el contenedor.

Resumen del proceso

El proceso utilizado para publicar el sitio con Docker y Nginx puede resumirse de la siguiente manera: 

1. Crear el archivo index.html.

2. Crear el Dockerfile.

3. Utilizar nginx:alpine como imagen base.

4. Copiar index.html al directorio utilizado por Nginx.

5. Construir la imagen:

   docker build -t mi-web-html .

6. Ejecutar el contenedor:

   docker run -d -p 8080:80 --name mi-web-container mi-web-html

7. Abrir:

   http://localhost:8080

Con este procedimiento se logra publicar una página web dentro de un contenedor Docker utilizando Nginx como servidor web.
